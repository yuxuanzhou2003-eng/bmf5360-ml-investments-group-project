# BMF5360 Project Story

Standalone bilingual (English / Chinese) visual briefing for the BMF5360 Machine Learning in Investments project.

Open `index.html` in a browser. It covers the investment idea, data scope and limits, baseline-model intuition, validation results, and next steps. The language toggle is in the top-right corner.

The page is an educational presentation artifact based on the repository's development and validation outputs. It is not investment advice and does not claim out-of-sample alpha.
