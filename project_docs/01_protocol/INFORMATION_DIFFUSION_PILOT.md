# Ripple Alpha：信息扩散基金可行性试验

日期：2026-09-07。结论：事件面板的数据流程可行，可以继续研究；尚未验证预测能力或投资收益。

## 本轮完成

## 时间对齐

事件预期只选择公告日期之前的同公司、同财季快照。网络使用公告日期之前最近 126 个交易日的收益，先减去用同一历史窗口估计的市场 beta 部分，再计算公司间残差相关性。每个事件选绝对相关性最高的三个其他公司，保留相关性的正负号。

入场参考时点设为公告日之后第一个观测交易日收盘；标签是随后五个交易日总回报减去同期 SPY 总回报。此处为数据标签定义，没有模拟订单或投资组合，不包含成本；这也意味着不计公告后至入场前的反应。

已通过：收益键唯一、预期快照严格早于公告日、网络历史严格早于公告日、入场晚于公告日、没有自身连边。供应商公告时区、EPS 调整口径及原始披露版本仍待独立验证，这些检查不等于完整证明没有前视偏差。

## 三个影响选题设计的发现

### 1. 财报信息与关系网络能够组成可用面板

已可以具体研究：源公司披露盈利信息后，其他公司的可执行时点之后是否仍有反应。季度预期带有目标财季结束日期，解决了年度预期不能直接匹配季度实际值的问题。首版建议以财报为事件锚点，新闻特征作为扩展。

### 2. 共同财报期是主要混淆因素

1,047 条邻居记录中，328 条在观察窗口内同时遇到接收公司自己的财报，占全部记录约 31.3%。另有 25 条涉及未取得财报历史的接收公司，不能判断是否重叠，已标为未知。接收公司自己的消息可能解释后续反应，不能轻易归因于源公司的信息。

这个重叠标签含有事后观察到的事件，仅用于诊断分组，不能直接当作预测特征或事前交易过滤条件。若策略要避开接收公司的财报，需要当时已知的公告日程。

### 3. 纯相关性网络不等于经济联系

选出的连边中有 175 条为负相关、115 条绝对相关性低于 0.2，绝对相关性中位数约 0.344。0.2 只是描述性诊断界线，不是调优后的交易阈值。

例如苹果 2015-01-27 财报事件，按该小股票池的滚动残差相关性选出的邻居为 XOM、MA、CVX，均为负相关。这并不证明数据错误，但说明强制选三个统计邻居可能与“经济联系中的信息传递”相距较远。不能将这些连边称为供应链，也不能从图注意力权重推断因果传播。

## 历史股票池复核

2015 与 2017 年的带日期 S&P 500 链请求，无论紧凑日期还是带连字符日期，均返回 503 个成员；已比较的紧凑日期结果与当前成员集合完全一致。因此这些返回结果未通过历史性验证，不能用于正式历史股票池。字段级指定历史日期仍返回空成员值。需要换历史成员数据路径或外部可核验来源；本轮没有把当前成员冒充历史成员。

## 建议收敛的正式研究问题

**财报信息能否沿可解释的公司关系网络，预测其他公司的后续收益？这种增量是否超越自身消息、行业共同冲击与简单邻居信号？**

模型比较保持三层：自身信息 LightGBM；加入同样关系与事件信息的 LightGBM；图注意力模型。用信息相同的第二层对照，才能判断图模型是否真有额外价值。

下一阶段的优先顺序：

1. 解决历史股票池与可追溯公司关系。历史行业关系或历史新闻共同提及可作为候选，供应链权限尚未验证。
2. 确认 EPS 调整口径、公告时区与历史预期定义，再扩展事件数据。
3. 完成事件研究与简单邻居基线，再训练图模型；加入保留行业结构的网络打乱对照及自身事件诊断。
4. 事先固定开发/验证/最终测试日期，按时间剔除跨边界标签；组合层合并重叠事件持仓，纳入成本、借券与风险暴露。

## 本地复现与证据

- diffusion_pilot_config.json：样本、日期、图窗口、标签参数与用途声明。
- probe_lseg.py 的 diffusion_discovery、diffusion_dates、diffusion_pilot 模式：小批量只读取数。
- build_diffusion_pilot.py：本地数据整理、季度匹配、历史网络和时间检查。
- data/access_probe/：逐请求摘要与原始数据。
- data/diffusion_pilot/events.csv：匹配的事件。
- data/diffusion_pilot/event_neighbor_panel.csv：事件—邻居面板。
- data/diffusion_pilot/summary.json：覆盖与检查结果。

本轮没有训练模型、报告 Sharpe 或生成可投资策略业绩。以上 2015–2017 年数据已属于开发阶段，不应再作为最终未触碰测试集。
