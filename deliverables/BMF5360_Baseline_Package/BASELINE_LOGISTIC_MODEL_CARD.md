# AI 股票日频 Logistic 基础模型卡

日期：2026-09-10  
状态：训练/验证阶段；测试期仍封存

## 你记得的 0.56 是什么

`ROC-AUC = 0.561559` 对应 **technical_plus_macro / Logistic**。它不是收益率回归，而是二元 Logistic 分类：预测一只 AI 产业链股票从形成日收盘买入并持有未来 21 个 SPY 交易日后，累计总收益是否高于同期 SPY。

标签为：

```text
y = 1，若 stock forward 21-session total return - SPY forward 21-session total return > 0
y = 0，否则
```

模型输出 `p_up`，即 `y=1` 的估计概率。模型不直接预测未来收益率大小。

## 样本和时间切分

- 候选池：49 个 AI 产业链 RIC；主训练样本实际覆盖 39 个，验证样本覆盖 44 个。
- 日频主表：110,829 个公司—交易日观察。
- 训练期：2015–2020，2,334 个 H21 非重叠锚点、444 个形成日。
- 验证期：2021–2022，992 个 H21 非重叠锚点、89 个形成日。
- 验证集正标签比例：50.7056%。
- 测试期：2023-01-01 至 2026-06-30，未打开目标、未预测、未计算指标。

这里没有随机打乱样本。每个标签跨越未来 21 个交易日，所以模型只使用预先选择的非重叠锚点；训练期内部时间折还要求训练行的 `exit_session` 严格早于下一折验证起点，以避免标签窗口重叠造成泄漏。

## 模型结构

模型是一条固定的 sklearn Pipeline：

```text
41 个原始输入变量
→ 训练期中位数缺失值处理 + 缺失指示变量
→ StandardScaler 标准化
→ LogisticRegression
→ p_up
```

Logistic 参数：

- `C = 1.0`
- `class_weight = balanced`
- `solver = lbfgs`
- `max_iter = 2000`
- `random_state = 5360`

缺失值中位数与标准化参数只在训练样本内拟合。没有零填充、前向填充、winsorization，也没有修改源数据。41 个原始变量经过 imputer 后形成 42 个模型输入，因为 `spread_median_60_bps` 额外产生了一个缺失指示变量。

模型形式为：

```text
p_up = sigmoid(intercept + Σ beta_j × standardized_feature_j)
```

拟合截距为 `0.008767`。系数作用在标准化及缺失处理后的变量上，表示在控制其他变量后对 log-odds 的边际方向；它们不是因果效应，也不能直接按原始单位解释。

## 41 个输入变量

### 21 个技术、流动性和市场变量

- 个股动量：1、5、20、60 日。
- 个股风险：20/60 日年化波动率、126 日 beta、126 日特质波动率、beta 有效观察数。
- 流动性：20/60 日成交量中位数、20/60 日美元成交额中位数、20/60 日报价价差中位数。
- SPY 状态：1、5、20、60 日动量与 20/60 日年化波动率。

### 20 个宏观变量

- VIX：水平、1/5/20 日变化、252 日历史分位数。
- 美国国债：3个月、2年、10年收益率水平及其 5/20 日变化。
- 美元：广义美元指数水平及 5/20/60 日变化。
- 利率曲线：10Y–2Y、10Y–3M 期限利差。

高收益与投资级信用利差的 6 个候选变量没有进入本模型，因为本地下载版本在训练和验证期没有可用覆盖；这些缺失没有被回填。

## 验证结果

| 指标 | technical-only Logistic | technical + macro Logistic |
|---|---:|---:|
| ROC-AUC | 0.539463 | **0.561559** |
| PR-AUC | 0.542098 | **0.552404** |
| Brier（越低越好） | 0.251095 | **0.250824** |
| 0.50 阈值方向准确率 | 51.61% | **56.45%** |
| pooled rank IC | 0.1403 | **0.1739** |
| 日均 rank IC | 0.0776 | **0.0858** |
| 诊断性 top-minus-bottom 21日超额收益差 | 0.615% | 0.524% |

加入宏观变量后，ROC-AUC 提高 `0.022096`，准确率提高约 `4.84` 个百分点，Brier 小幅改善。诊断性的 top-minus-bottom spread 反而略低，因此这版结果支持“宏观状态改善方向分类”，还不能单独证明可交易收益提升。

作为参照，同一批验证样本上的 technical + macro Random Forest AUC 为 `0.536190`；后来加入 AI 行业状态的 Logistic AUC 为 `0.579940`。因此 `0.561559` 是宏观增强 Logistic 基础模型，不是当前数值最高的 Logistic。

| 变量 | 标准化系数 |
|---|---:|
| SPY 60日动量 | -0.3508 |
| 个股20日成交量中位数（log1p） | +0.2514 |
| SPY 20日波动率 | -0.2265 |
| 3个月国债收益率20日变化 | +0.1743 |
| 60日价差缺失指示变量 | +0.1714 |
| 个股60日美元成交额中位数（log1p） | -0.1677 |
| 个股1日动量 | -0.1556 |
| 10年国债收益率20日变化 | -0.1381 |
| 个股5日动量 | -0.1296 |
| 个股60日波动率 | -0.1284 |

系数显示这版模型不是简单的“动量越高越看多”。它在控制多种相关变量后同时使用短期反转、较长期动量、市场波动、利率变化和流动性状态。宏观和技术变量之间存在相关性，系数的符号可能随特征集合变化，解释时应结合 permutation importance、稳定性和经济逻辑，不能把单个系数当作独立因果结论。
